# Archivo histórico

Estos documentos se conservan para rastrear cómo se aprobaron fases y decisiones. No describen necesariamente el comportamiento vigente.

- `fases/`: actas, excepciones y evidencia de las fases 0–12;
- `diseno/`: propuestas y actas visuales sustituidas por el plan y las guías actuales;
- `planificacion/`: planificación inicial y registro histórico de herramientas.

Para conocer el estado real consulta [Estado actual](../ESTADO-ACTUAL.md). Una corrección nueva debe actualizar los documentos vigentes, no reescribir estas actas.
