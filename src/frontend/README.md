# Lou Barbershop Web

PWA React/TypeScript. La estructura protege la dirección de dependencias:

- `core`: políticas y tipos puros; no importa React ni adaptadores.
- `infrastructure`: navegador, HTTP y persistencia técnica.
- `presentation`: componentes, layouts, páginas y hooks.
- `composition`: ensambla providers, rutas y adaptadores.

Comandos: `npm run dev`, `npm run build`, `npm run test`, `npm run lint` y `npm run storybook`.
